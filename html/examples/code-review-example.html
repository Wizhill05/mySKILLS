01. Executive Summary & Assessment

This pull request introduces structured JSON schema enforcement for LLM resume generation output via Server-Sent Events (SSE) streaming. Overall architectural direction is solid, leveraging Zod structured schemas for validation before database persistence.

However, during in-depth code audit, two critical security and memory-safety vulnerabilities were identified in stream chunk buffering and HTML canvas rendering. These issues must be addressed before this PR is approved for production deployment.

04. In-Depth Technical Findings & Concrete Patches

[ERROR] Critical Vulnerability: Unbounded SSE Stream Buffer (ai-generator.ts:88)

The stream reader accumulates all delta tokens into a single heap string without enforcing a maximum byte limit. If an upstream LLM model hallucinates or fails to emit a stop token, worker memory will grow uncontrollably, resulting in Node process OOM (Out Of Memory) crash.

// Recommended Fix in src/services/ai-generator.ts:
const MAX_STREAM_BYTES = 512 * 1024; // 512 KB limit
let accumulatedBytes = 0;

for await (const chunk of stream) {
  accumulatedBytes += Buffer.byteLength(chunk.delta, 'utf8');
  if (accumulatedBytes > MAX_STREAM_BYTES) {
    stream.abort();
    throw new StreamPayloadTooLargeError('Stream exceeded 512KB payload ceiling');
  }
  accumulator += chunk.delta;
}
[ERROR] Critical Vulnerability: SVG/HTML Injection in PDF Rendering (pdf-canvas.ts:114)

User-supplied text from the LLM is directly inserted into SVG markup template strings. A malicious prompt injection could force the model to output <script> or <foreignObject> tags, executing arbitrary code within the PDF headless Chromium renderer.

// Apply DOMPurify or sanitize-html before SVG interpolation:
import sanitizeHtml from 'sanitize-html';

export function escapeSvgText(input: string): string {
  return sanitizeHtml(input, { allowedTags: [], allowedAttributes: {} });
}
