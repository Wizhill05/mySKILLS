02. Critical Security & Architecture Findings

[ERROR] Critical Vulnerability 1: Unbounded Stream Buffer Memory Leak (DoS Vector)

In src/services/ai/stream-buffer.ts:44, incoming SSE stream chunks are accumulated into an in-memory buffer without a maximum byte length cap. If an upstream LLM provider produces malformed or unbounded tokens, a single rogue client request can consume node heap memory to exhaustion (OOM crash).

Remediation: Enforce a strict MAX_BUFFER_BYTES = 512 * 1024 (512 KB) hard limit. Abort stream with HTTP 413 Payload Too Large if exceeded.

[ERROR] Critical Vulnerability 2: Stored Cross-Site Scripting (XSS) in HTML Exporter

In src/services/export/html-renderer.ts:89, user-supplied project descriptions are injected into the template using raw string interpolation (${entry.description}) instead of DOM escaping or a sanitized AST walker. An attacker can craft malicious prompt responses that execute arbitrary scripts in the context of other users viewing shared resumes.

Remediation: Pass all user-controlled text strings through escapeHtml() or use DOMPurify before generating the export preview.
